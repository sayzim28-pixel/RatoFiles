# Rato Files

Projeto iOS profissional (SwiftUI, iOS 16+) para gerenciar documentos importados para o aplicativo.

## Funções

- Importar arquivos pelo app Arquivos
- Copiar, colar e duplicar arquivos
- Renomear e excluir arquivos no espaço do app
- Compartilhar por meio da folha nativa do iOS
- Ilustração original de rato na tela vazia

## Importante

O iOS não permite que apps acessem pastas de sistema ou arquivos de outros apps. O Rato Files trabalha nos documentos do próprio app e importa itens que o usuário escolher no app Arquivos.
